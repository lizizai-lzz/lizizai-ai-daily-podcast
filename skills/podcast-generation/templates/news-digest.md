# 新闻资讯播客模板

使用此模板将新闻快讯、行业动态或趋势分析转换为播客。

## 输入准备

1. **提取新闻要素**：确保5W1H（谁、什么、何时、何地、为什么、如何）
2. **补充背景信息**：相关行业背景、历史脉络
3. **多角度分析**：利弊分析、不同利益方观点

## 示例转换

### 原始新闻内容：
```
OpenAI发布GPT-5模型，在推理能力和多模态理解方面取得重大突破。
新模型在数学推理基准测试中提升了40%，支持原生图像生成和视频理解。
```

### 播客对话内容：
```
男主持: 大家好，欢迎收听本期AI前沿速递。今天有个大新闻必须聊聊——OpenAI终于发布了GPT-5！
女主持: 哇，等了好久终于来了！我听说这次提升特别大？
男主持: 确实，最大亮点是推理能力。数学推理基准测试直接提升了40%，这个幅度非常夸张。
女主持: 40%？那基本是碾压级别的进步了。不过说实话，普通用户可能更关心的是实际体验会有什么不同？
男主持: 好问题！还有一个重要更新是原生支持图像生成和视频理解了……
```

## 生成命令

```bash
python3 scripts/generate.py \
  --content-file ./news-article.md \
  --output-file ./generated-podcasts/news-digest.mp3 \
  --script-file ./generated-podcasts/news-digest-script.json \
  --transcript-file ./generated-podcasts/news-digest-transcript.md \
  --locale zh \
  --style news
```

## 新闻播客技巧

- 开头用"大新闻"、"重磅"等词汇吸引注意
- 按"发生了什么 → 为什么重要 → 意味着什么"展开
- 适当加入个人观点和预测
- 对比历史类似事件，帮助听众理解
- 结尾给出行动建议或关注方向
