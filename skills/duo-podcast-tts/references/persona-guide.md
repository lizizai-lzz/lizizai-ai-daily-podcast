# 角色定位与写作指南

## 一、按选题推荐角色原型

先判断选题类型，从下表选男女角色原型；再回 voice-catalog.md 挑音色（男声列 / 女声列）。

| 选题类型 | 男角色原型（示例音色） | 女角色原型（示例音色） | 关系基调 |
|---|---|---|---|
| 科技 / 教育 | 科技少年、技术极客（Dylan / Ethan） | 甜妹、知性学习者（Maia / Ono Anna） | 男主讲，女提问/惊叹 |
| 新闻 / 国际大事 | 新闻主播、时政分析（Neil / Andre） | 知性记者、冷静观察（Serena / Katerina） | 主持人主导，嘉宾补充 |
| 财经 / 商业 | 沉稳分析师（Kai / Andre） | 好奇学习者（Mia / Serena） | 讲师带学员 |
| 职场 / 成长 | 导师、前辈（Elias / Li） | 后辈、学员（Stella / Nini） | 传道解惑 |
| 情感 / 生活 | 好友、邻家男（Eric / Rocky） | 闺蜜、邻家女（Sunny / Kiki） | 平等闲聊 |
| 娱乐 / 角色向 | 戏感男（Ryan / Peter） | 搞怪/萌系女（Momo / Chelsie） | 捧逗互动 |
| 知识 / 科普 | 说书人、讲师（Neil / Elias） | 求知者（Maia / Serena） | 主讲+追问 |

## 二、角色设定要点

写稿前把两个角色的「一句话人设」写清楚，作为全文口吻基准：

- 男：性格、口音/方言、职业或身份、专业领域、说话风格（爱用比喻？爱摆数据？）
- 女：性格、与男生的关系（仰慕/平等/师徒/闺蜜）、提问方式、情绪反应
- 关系基调决定对话张力：仰慕型 → 女多用惊叹与追问；平等型 → 双方互抛观点；师徒型 → 男给方法，女要落地

示例（北京科技少年 + 温柔甜妹）：
- 男：浓厚北京味科技少年，国际大事门儿清，分析有理有据（得嘞、甭急、倍儿、你猜怎么着）
- 女：温柔可爱甜妹，满眼崇拜（"李哥你怎么什么都懂啊""那这句我能记一辈子"）

## 三、主导比例

- 默认男生主导：男生约 60-75% 的说话量（段落更长、次数相当或更多）
- 用户指定时按其要求；女生主导同理
- 实现方式：主讲的段落 80-200 字，配角的段落 15-40 字（惊叹/追问/接话）

## 四、口吻与写作细则

- 方言/京味浓度适中：能体现人设即可，别让 TTS 卡壳（儿化音每句最多 1-2 处）
- 短句推进：单句尽量 ≤ 25 字，用逗号/句号控制节奏
- 问句制造对话感：每 2-4 句里有一句提问或反问
- 数据支撑：男主讲的分析段尽量带具体数字/案例（"五十四个大学生""六个百分点"）
- 情感标注：每行给 `emotion`（平静/认真/好奇/惊讶/开心/坚定/神秘/悲伤），让 TTS 段间情绪有起伏，别全篇一个调
- 结构：开场定题 → 抛出悬念/案例 → 两轮问答推进 → 三条行动建议 → 金句收尾 + 互动提问
- 结尾金句示例："它不收你钱，它收你的能力"（用反转/排比句式）

## 五、合成注意事项

- 默认模型 `qwen3-tts-flash` 不支持 instruction 情感指令，情感靠台词与标点表达（问号、感叹号、省略号）
- 需要指令级情感/拟声时：换 `qwen3-tts-instruct-flash`（音色集合不同，先实测）或 MiniMax speech-2.8（文本内 `(laughs)/(sighs)` 语气词标签）
