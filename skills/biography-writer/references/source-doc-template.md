# 母文模板（source-doc-template）

本文件是 biography-writer 阶段 2 的执行细则。读取 `00_raw/*` 中所有素材后，按本模板整理为 `10_source.md`。

## 一、母文定位

母文是**事实仓库**，不是叙事。后续所有创作（大纲、正文）的唯一事实来源就是这份文档。所以：

- 信息密度优先于可读性。
- 每条事实挂来源 URL，无来源的事实进入"待澄清问题"区。
- 不做主观评价、不做叙事化加工。
- 矛盾信息全部保留，标注矛盾点。

## 二、模板结构

```markdown
# {人物名} — 母文

> 生成时间：YYYY-MM-DD
> 素材来源：anysearch（N 条） + agent-reach（M 条）
> 总字数：约 X 字

## 1. 基础档案

- 中文译名：
- 英文原名：
- 生卒年：
- 国籍：
- 身份标签：（如"OpenAI CEO / 连续创业者 / 投资人"）
- 当前机构：
- 主要领域：
- 一句话定位：（不超过 30 字，事实陈述，不带评价）

## 2. 时间线（按年份）

按时间顺序列出关键事件，每条一行：

| 年份 | 事件 | 来源 |
|------|------|------|
| 1985 | 出生于芝加哥 | [来源](url) |
| 2005 | 从斯坦福辍学 | [来源](url) |
| ... | ... | ... |

时间线密度：至少覆盖 10 个关键节点，最多不超过 30 个。

## 3. 关键人生节点（5-10 个）

每个节点独立成节，深度展开。

### 节点 1：{标题}

- **时间**：
- **背景**：（当时人物处境、行业状态）
- **经过**：（具体发生了什么）
- **结果与影响**：（这一节点带来了什么）
- **公开言论**：（人物对此节点的公开表态，带原文）
- **来源**：[url1] [url2]

（重复 5-10 次）

## 4. 重要作品 / 产品 / 成就

按时间或重要度排列。每项：

### 成就 1：{名称}
- 时间：
- 内容：（这个产品/作品/成就是什么）
- 影响：（行业反响、用户规模、学术引用等可量化指标）
- 人物自评：（如有公开表态）
- 来源：

## 5. 公开发言摘录

按主题归类，每条带原文和来源。

### 5.1 技术观 / 专业观点
- "..." — [2023 年 X 访谈](url)
- "..." — [Twitter 2023-05-12](url)

### 5.2 商业观 / 行业判断
- ...

### 5.3 价值观 / 个人信念
- ...

### 5.4 争议言论
- ...

## 6. 公开报道视角

### 6.1 正面报道（媒体如何赞美）
- 报道 1：[标题](url) — 核心观点摘要
- ...

### 6.2 中立/分析报道
- ...

### 6.3 批评报道
- ...

## 7. 争议与不同声音

每个争议独立成节。

### 争议 1：{标题}
- 时间：
- 事件经过：
- 不同立场：
  - 立场 A（支持方）：...
  - 立场 B（批评方）：...
- 人物回应：
- 后续发展：
- 来源：

## 8. 行业上下文

人物不是孤立的。记录：

- **同代人/同代人中的对手**：
- **所属浪潮/运动**：（如"深度学习复兴"、"Web 2.0"、"生成式 AI 浪潮"）
- **关键合作伙伴与对手**：
- **行业的整体评价**：（业内对这个人物的常见看法，区分正面与中立）

## 9. 待澄清问题

素材中矛盾或缺失的关键信息，列出后供阶段 3、4 处理。

- 问题 1：母文 A 说 X 出生于 1985，母文 B 说是 1984 — 倾向采用 X，因 Y。
- 问题 2：关于 {关键事件} 的具体经过，公开资料只字未提，需在传记中模糊处理或标注推断。
- 问题 3：...

## 10. 素材统计

- 总素材字数：约 X 字
- 来源数量：anysearch N 条 / agent-reach M 条
- 覆盖维度自评：
  - [x] 基础生平
  - [x] 关键事件深度
  - [x] 公开发言
  - [x] 公开报道（含批评视角）
  - [x] 争议
  - [x] 行业上下文
  - [ ] {未覆盖项}
```

## 三、整理规则

### 3.1 事实聚合

同一事件可能来自多个素材。聚合时：
- 主体叙述合并，保留最具体的细节。
- 不同来源说法矛盾时，**两条都保留**，在事件描述后注明"（另一说：...）"。
- 不主动判定哪条是真，留给阶段 3、4 处理。

### 3.2 引语处理

- 保留原文，不改写。
- 重复的引语只保留一条，但合并所有出处。
- 转述他人评价（不是人物原话）的引语，归到"公开报道视角"，不进"公开发言"。

### 3.3 时间线去重

同一事件在不同素材中多次出现时，时间线只保留一行，但来源列挂多个 URL。

### 3.4 争议保留

母文**禁止**抹平争议。即使某条批评报道只有 1 个来源，也要完整记录。传记的张力来自这些不同声音。

## 四、完成自检

母文完成前，逐条检查：

- [ ] 基础档案 9 项齐全
- [ ] 时间线至少 10 个节点
- [ ] 关键人生节点至少 5 个，每个都有"经过 + 来源"
- [ ] 公开发言至少 10 条且分类清晰
- [ ] 公开报道三个视角都有内容（即使某一视角只有 1 条）
- [ ] 至少 1 个争议被完整记录
- [ ] 行业上下文不少于 200 字
- [ ] 待澄清问题列出所有矛盾与缺失
- [ ] 每条事实都挂了来源 URL

不通过的项目回到 `00_raw/` 补充素材，重新整理对应章节。
