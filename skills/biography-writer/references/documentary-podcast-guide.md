# 纪录片式播客脚本指南（VO + SOT）

> 适用：李自在AI人物志等以真实人物故事为主的播客。把纯旁白稿改造成「VO 旁白铺垫 → SOT 人物原声」结构。
> 经验来源：E07 Jason宅邸青年 制作复盘。

## 一、什么是 VO / SOT

- **VO**：你的叙事旁白，负责交代时代、背景、困境、前因后果，把故事铺垫到位。
- **SOT**：人物**真实公开采访原声片段**，不是 AI 模仿声音，是截取现实中他真实说过的录音。

规则：
1. VO 负责铺垫与承接；讲到情绪关键点、人生转折点，切一段本人原声（SOT），让人物自己说话。
2. 原声结束后切回 VO，承接、解读、往下推进故事。
3. **不要大段放原声**：单段 SOT 建议 20-45 秒，太长听众容易走神。
4. **SOT 只放人物本人（或用户明确同意纳入的对话方）的原声**，第三方评论/博主观点一律转由 VO 讲述。

## 二、脚本格式（可直接复制使用）

```markdown
【VO｜旁白，无音乐】
[平静地] 旁白文字……
[自然叙述地] 旁白文字……

【SOT｜人物名原声，30秒｜来源：{采访/视频名} v1 01:12–01:42】
（人物原声文字，方便剪辑对齐）
“……原话……”

【VO｜旁白】
[自然叙述地] 承接文字……
```

标注要点：
- `【SOT｜…，XX秒｜来源：…】`：必须写清时长和来源（视频/采访文件名 + 起止时间戳）
- SOT 块内写**原声实际内容**（转写稿），供剪辑对齐
- VO 段落按段加 `[情感标签]`（沿用 podcast-script-guide.md 的标签池，克制为主）

## 三、VO 写作规则

- 每段 VO 约 40-90 秒（约 120-260 字），功能是铺垫/承接，不是复述原声内容
- **引语让给 SOT**：旁白不要重复引用原声里已经说过的话，避免"旁白说完、原声又说一遍"
- 段落结构：抛出背景/悬念 → （SOT）→ 解读/推进
- 情感标签沿用 podcast-script-guide.md：中性标签 ≥70%，点睛 ≤8 处，禁语速/综艺标签

## 四、SOT 剪辑规范（听感关键，必须遵守）

1. **必须让人物完整说完那句话**：以转写 JSON 的**词级时间戳**定位句子结束时间，剪切终点 = 句尾时间 + 0.6 秒尾音/呼吸余量。**绝不允许切在句中**（若下一句紧接、无空隙，即上一句 end_time == 下一句 begin_time，剪切终点 = 句尾本身）。
2. **`-ss` 必须放在 `-i` 之前（输入 seek）**：`-ss` 放在 `-i` 之后（输出 seek）与 `loudnorm` 组合时，中段切片会输出全静音（实测：max_volume -91dB）。这是最容易踩的坑。
3. **`atrim` 之后必须加 `asetpts=PTS-STARTPTS`**：否则 `volume='if(lt(t,...))'` 包络的 `t` 从源时间戳起算、判定错乱（实测：BGM 尾奏在 17s 后消失）。
4. 淡入：0.3 秒；淡出：从"说完之后 0.7 秒"开始、0.4 秒内淡出（实测：只晚 0.2-0.4s 会被听众反馈"话没说完就被减弱"）——淡出落在呼吸/尾音上，人声不会有"被消没"的感觉。
5. 响度：`loudnorm=I=-16:TP=-1.5:LRA=11`，与 VO 一致；统一 `aresample=24000,aformat=channel_layouts=mono`。
6. 时长：单段 20-45 秒（视句子完整性灵活，可略超）。
7. 如果原声里有明显环境噪音影响听感，做轻度降噪；不要改变语速。
8. 每段剪完必验证：`ffmpeg -i sot_XX.mp3 -af volumedetect -f null -` 确认有声（max_volume > -30dB）；必要时把切片再转写一遍核对句子完整、无半句残留。

## 五、结尾背景音乐（可选）

人物志 BGM 由 `config/profile.json` 的 `paths.bgm_biography` 指定（不随库分发，需自备；推荐连续织体、无静音空洞的曲目）。选择任何 BGM 前先测电平（`ffmpeg -i <bgm> -af volumedetect -f null -`）：**均值低于 -25dB 或含长静音空洞的曲目不可用**（实测：BGM 库冥想曲均值 -27dB 且稀疏，混入后几乎不可闻）。

- 音乐从**正文最后一段旁白（收束段，如"……逝世"句）开始时**垫入，与片尾共用同一条连续包络（不是只从片尾开始）
- 收束段起 1.5 秒淡入 → 旁白/片尾口播期间压低至 **0.125**（不盖人声）→ 口播读完后 1.5 秒线性渐强至 **0.55** → 保持 4 秒 → 再 3 秒渐弱收尾
- **跨段连续性**：收束段与片尾的 BGM 用同一源文件的两个连续偏移（收束段 `atrim=end=<vo13时长>`，片尾 `atrim=start=<vo13时长>`），且 atrim 后加 `asetpts=PTS-STARTPTS`，保证接缝处音量与旋律无缝
- **必须取曲目的一段连续旋律，禁止拼接、循环、剪切后重复播放**；音量用平滑包络实现，不能有断层

## 六、整期组装顺序（纪录片式，默认）

```
品牌片头 →（蒙太奇冷开场·可选，带BGM）→（个人推荐·可选，无BGM）→ 纪录片正文（VO/SOT，无BGM）→ 片尾（带BGM尾）
```

- 正文（VO + SOT）一律无背景音乐
- 蒙太奇冷开场是独立声音设计，可保留音乐
- 最终统一 24000Hz 单声道、96kbps MP3

## 七、时点（Show Notes）

时点按**实际段落时长**计算，而不是章节字数比例：
- 正文各 VO/SOT 段的起点 = 片头 + 蒙太奇 + 个人推荐 + 停顿 + 正文内累计时长
- 每 1-2 个 SOT 对应一个时点条目，标题用该段主题（如"开场：被大V当众批评，只说没生气"）
