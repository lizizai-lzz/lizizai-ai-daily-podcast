# 开源推广：AI 播客全流程制作技能合集

[温暖地]最后说个自己的事。你听到的这档节目，从每天的选题、写稿，到配音、封面，再到自动传上小宇宙，是我在 agent 里跑起来的一整套流水线。现在，这套东西我完整开源了。

[认真地]GitHub 搜索 lizizai-ai-daily-podcast，十个技能，从选题调研、口播稿生成，到 TTS 配音、成品校验、定时发布，一条链路全都在。但我最想让你看的，不是代码本身，是流水线里那些只有真的天天跑才会遇到的细节问题：口播稿怎么去掉 AI 味、数字和单位怎么念才顺耳、两条音轨的响度怎么对齐、定时发布要留出多少审核提前量、开源音效的署名义务怎么处理。这些坑我一个一个踩过来，解决方案也原样写进了每个技能的说明里。

[真诚地]与其说这是个开源项目，不如说是我三百多期攒下来的一份踩坑笔记。

[坚定地]去 GitHub 把它克隆下来，照着 README 走一遍，你也能让 agent 帮你做一档自己的节目。
