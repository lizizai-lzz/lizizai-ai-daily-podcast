# 流水线详解（Phase 0-4）

本文以主流水线 `ai-daily-podcast` 为例拆解整条制作链路。行业洞见单集（`industry-insight-podcast`）与人物志（`lizz-biography-podcast`）共用其中的大部分阶段，差异点在文末。

> 实操以各 SKILL.md 为准，本文是给人读的讲解版。

## Phase 0：初始化与连续性

播客最怕「每天都是第一期」。流水线在生成前先解决三件事：

1. **确定运行模式**：日报套餐（每日精选 + 开源解读 [+ 行业洞见]）还是独立单集，产物目录 `~/.daily-ai-news/data/{date}/podcast/`。
2. **读取播客历史档案**（`~/.daily-ai-news/history/podcast_history.md`）：提取近 7 天已选入的开源项目、新闻标题、观点和**开头手法**，形成选题黑名单与「7 天轮换约束」——下一期的开头手法必须避开近 7 天用过的。
3. **输出连续性简报**：知识库查询记录、主题饱和标签、可延续的叙事线索（如「Anthropic 融资进度」这类可以做成连载的故事线），写入选题文件的附录。

## Phase 1：选题判断

**硬排除**（三条栏目的公共底线）：Agent 安全、漏洞（CVE、攻击链、提示注入等）两类主题不入选；但不扩大化——隐私、监管、诈骗只有当核心议题确实属于这两类时才排除。

三条栏目的选题入口各不相同：

- **每日精选 / 开源解读**：从当日 AI 日报逐模块分析，对照历史档案做**项目级 / 新闻级 / 主题级**三级去重，强制输出去重检查表（dedup_check）。
- **行业洞见**：不从日报选题。从知乎 AI 大众热点找 ≥3 个候选（优先工作、收入、教育、消费、家庭等普通用户议题），记录可达的浏览量/关注数/回答数（不可见就写「不可见」，禁止估算），按**大众相关性、知乎热度、论据强度、新鲜度、行动价值**五维评分，选 ≥7 分的最高分主题，再用 ≥3 条外部可信来源核验。

## Phase 2：脚本生成

渐进式加载是关键设计：**生成哪一栏，只读哪一栏的模块文件**（`modules/daily-brief.md` / `opensource.md` / `industry-insights.md`），三个栏目的文风、标题法、密度线互不通用。

栏目模块产出带 `[情感标签]` 的口播稿后，立即生成 `config.json`（标题、简介、封面数据、音频路径；时长/大小等字段留 null，Phase 3C 回填）。

## Phase 2.6：口播校验门禁（流水线的灵魂）

这是整套流程区分「念稿」和「说话」的核心，五步强制依次执行，未 PASS 禁止录音：

### 2.6A de-AI 去 AI 味

清理二分对照壳（「不是 A 而是 B」全文最多 1 处）、协作口吻（「我先来看」「接下来我们聊」）、路标词（「更关键」「换句话说」合计 ≤2 次）、讲义动作（「盘一盘」「划重点」），打破段落同构，段尾允许停在事实/引语上。

### 2.6B 情感标签修正

- **禁用一切语速类标签**（`[放慢语速]` 等）——节奏由标点和断句承担
- 相邻段情感过渡要自然（`[严肃认真地]` 不能直接跳 `[热情欢快地]`）
- 同一标签全文 ≤3 次
- 每日精选强制跑 `scripts/check_broadcast_speakers.py`：**一条新闻只能有一位主持**（切换点只允许在 `===` 分隔符上）

### 2.6C 数字与单位转口播

TTS 念错的源头是数字书写方式。强制转换表：

| 原文 | 转为 | 原因 |
| --- | --- | --- |
| `7/20` | `7月20日` | 斜杠会念成「七杠二十」 |
| `2024年` | `二零二四年` | 避免「两千零二十四」 |
| `2亿` | `两亿` | 量词前「二」读「两」 |
| `$100` | `100美元` | 符号不读 |
| `10%` | `百分之十` | 百分号念法不稳 |
| `100MB` | `100兆` | 英文字母逐字念灾难 |

### 2.6D 口播声纹校验（程序化硬门禁）

`scripts/check_oral_voice.py --type {daily_brief|opensource|industry}` 逐稿检查，**硬指标 FAIL 即退出码 1**：

| 栏目 | 人称词/千字 | 真问句/千字 | 书面连接词 | 平均句长 |
| --- | --- | --- | --- | --- |
| 每日精选 | ≥ 20 | ≥ 2.5 | ≤ 2 | 8–18 |
| 开源解读 | ≥ 25 | ≥ 2.5 | ≤ 2 | 8–18 |
| 行业洞见 | ≥ 25 | ≥ 2.5 | ≤ 2 | 8–18 |

**TTS 禁区**（硬 FAIL）：专有名词后、数字/评分后、纯事实陈述句尾出现 啊/呢/吧/嘛/呀。语气词密度 2–5/千字仅 WARN。

> 设计逻辑：真实播客和 AI 稿的差距不在句长，在「有没有人在场」。缺人称就补「我/我们/你」起头的判断句和真问句，**不要**堆语气词凑数、也不要把句子拆短。

### 2.6E 覆盖写入

处理后的内容覆盖写回脚本文件，才允许进 Phase 3。

## Phase 3：音频与封面

**3A MP3**：三条脚本可并行合成。

- 每日精选：`generate_news_broadcast.py`，A/B 音色按 `===` 条目交替，合成前程序级校验切人规范；条目间自动插翻页音效（默认 −8dB）；支持 `--reuse` 按文本哈希缓存只重录变化条目
- 单人栏目：`generate_tts_solo.py`（火山引擎 Seed-TTS，情感标签语法）
- BGM：片头 5s / 片尾 8s，同一首曲同一段切片，默认值集中在 `scripts/podcast_audio.py`；音量 −11dB 是实测与人声压平的值
- CC BY 4.0 署名由 finalize 自动追加，不要手写

**3B 封面**：`templates/cover_template.html`（复古中文报纸风格）+ Playwright 截图 2048×2048 PNG，三个栏目自动切换配色（墨黑/靛蓝/赭棕）。

**3C 回填校验**：`finalize_podcast.py` 一条命令完成 `~` 路径展开、时长/大小/码率回填（直接读 PNG 头和 ffprobe，不手工取值）、BGM 署名追加、成品校验（文件缺失/封面尺寸不对/字段为空任一命中即退出码 1，禁止上传）。

**3A.1 栏目推广**（可选）：`assets/promotions/{date}.json` 不存在则回退 `default.json`，按 `active_from/until` 生效期把推广片段追加到成品（幂等，靠标记文件防重跑）。

## Phase 4：交付与发布

1. 交付文件摘要表；确认 finalize 退出码 0
2. **强制**：把当日选题（含开头手法）追加写入播客历史档案顶部——这是明天 Phase 0 的去重数据源
3. 上传走 `xiaoyuzhou-upload`（Playwright 自动化）：标题查重防重复创建、AI 生成声明勾选、定时发布（同天发布间隔 ≥4 小时）、上传后回读三重验证（同名单集数 / pubDate / AI 声明已开启）

## 两个独立技能的差异

### industry-insight-podcast（行业洞见单集）

- **zhihu / dev 双模式**：zhihu（默认）走知乎大众热点 + DeepSeek Search/Fetch + 来源 A/B/C/D 分级 + 强制理论支持（一个主理论 + 一个竞争解释 + 原始论文链接 + 口播翻译）；dev（大咖言论版）从当日日报「观点与言论」选大咖原话，any-search 佐证，面向独立开发者
- **Gemini 写作阶段**：构造系统提示词（上下文 = 选题 + 母文 + 原文台账 + 理论支持），调用前展示给用户确认；Gemini **不得新增母文外事实**
- **母文先行**：先产出 `source_brief`（核心判断、支持/反驳/补充三类材料、来源等级、生活类比、行动建议），给用户确认后才进入写作
- 支持一周批量排期：先出周排期和候选池，五期覆盖不同生活场景，批量母文 → 统一查重 → 逐集过门禁 → 逐集上传
- 全历史主题族去重：额外维护 `industry_topic_dedup_index.md`，相邻主题必须同时具备新事件、新证据、新机制、不同行动才可再选

### lizz-biography-podcast（人物志）

VO 旁白（火山 TTS）+ 人物真实原声 SOT 的纪录片结构，不支持纯旁白：

1. B 站采集人物原声 → 听悟 ASR **词级时间戳**转写（SOT 剪辑唯一依据）
2. 只选人物本人 20-45 秒、情绪到位、自成一段的原话做 SOT；第三方评论一律转 VO
3. VO/SOT 交替组装正片（正文无 BGM），收束段起 BGM 垫入，片尾共包络渐强
4. 大量 ffmpeg 实测踩坑已固化成规则，见 [lessons.md](lessons.md)

```
{date}/podcast/
├── topic_selection_{date}.md            # 选题判断（含去重检查表）
├── research_supplement_industry_{date}.md
├── source_brief_{date}.md               # 行业洞见母文
├── outline_{date}.md                    # Gemini 大纲
├── knowledge_audit_{date}.md            # 研究审计（内部，不上传）
├── script_{type}_{date}.md              # 口播稿（已过门禁）
├── config.json                          # 元数据（已回填校验）
├── cover_{type}_{date}.png              # 2048×2048 封面
└── {type}_{date}.mp3                    # 成品音频
```
